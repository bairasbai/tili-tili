# Живой обход ролей и сценариев

Кликом, а не снимками (R-263): headless-Chromium открывает каждый маршрут роли и нажимает каждую кнопку по центру,
как палец; потом восемь сквозных сценариев с проверками на каждом шаге. Впервые проведён 2026-09-19
(JOURNAL «Живой обход ролей»), с 2026-09-26 живёт здесь и гоняется в GitHub Actions — проверка «Живой обход».

## Запуск в GitHub

Вкладка **Actions → Живой обход → Run workflow**. Сам запускается и при правке этой папки или
`.github/workflows/walkthrough.yml`. Чистая база, PostgreSQL 16 и Redis 7, свои одноразовые секреты — ноутбук не нужен.
Сводка — в логе шага «Обход» и на странице запуска; полные отчёты — артефакт `walkthrough-out`.

## Запуск локально

Сначала тесты, потом обход — не одновременно: база общая (R-177).

```bash
export LIVE_DIR=/tmp/tili-walk                 # состояние прогона: токены, state-файлы, отчёты — вне репозитория
export PW_CORE=/путь/к/node_modules/playwright-core   # если playwright-core не ставится рядом
mkdir -p "$LIVE_DIR"
# бэк (лог нужен раздатчику — из него берутся dev-коды входа), фронт, раздатчик:
(cd ../../backend && REDIS_URL=redis://127.0.0.1:6379 node node_modules/tsx/dist/cli.mjs src/index.ts > "$LIVE_DIR/be.log" 2>&1 &)
# фронт — прод-сборкой: dev-версия React под StrictMode шлёт каждый запрос дважды и упирается в лимит частоты
(cd ../../app && NODE_ENV=production node node_modules/vite/bin/vite.js build && node node_modules/vite/bin/vite.js preview --host 127.0.0.1 --port 3000 --strictPort > "$LIVE_DIR/fe.log" 2>&1 &)
node tok-server.mjs &
WALK_STAFF_PHONE=+7XXXXXXXXXX bash walk.sh   # существующий сотрудник панели; на чистой базе — WALK_MAKE_STAFF=1
```

Фикстуры — одноразовые аккаунты dev-базы с номерами `+79<набор><nnn>`: каждый прогон заводит свой набор, прошлые
не мешают. Секреты скрипты берут из окружения поверх `backend/.env` (`backend-env.mjs`). Скрипты фикстур делают паузу
между запросами: сервер пропускает не больше 10 запросов в секунду на пользователя.

## Что внутри

| Файл | Что делает |
|---|---|
| `walk.sh` | Всё по порядку: фикстуры → обход ролей → сценарии → сводка |
| `mk-fixtures.mjs`, `fix-to-tok.mjs`, `mk-ids.mjs`, `mk-vendor2.mjs` | Аккаунты ролей, свадьба, сделка, чаты, гость; идентификаторы маршрутов |
| `tok-server.mjs` | Раздатчик на 127.0.0.1:3999: токены ролей, dev-код входа из лога бэка, приём отчётов |
| `run.sh`, `couple-all.sh`, `roles-all.sh`, `mkjob.mjs`, `crawl-run.cjs`, `crawl-body.js` | Обход кнопок по ролям |
| `flow-*.cjs`, `flow-lib.cjs` | Восемь сценариев: онбординг, подрядчик, сделка, заявка, команда, прочее, разрушительные |
| `summary.mjs` | Сводка; код выхода 1 — только явная поломка (сценарий, падение обходчика, экран ошибки) |
| `show.cjs`, `api.mjs`, `api-state.cjs` | Разбор: таблица отчёта, вызов API от имени роли |
