# Тили-тили — Карта экранов и элементов (SSOT для разработки)

> **Назначение.** Этот файл — карта всех экранов, блоков и интерактивных элементов приложения. Любой ИИ-разработчик (Kimi K3, Claude Code или другой) обязан прочитать его перед изменением UI.
>
> **Правило R-MAP (обязательное):** каждый раз, когда добавляется/изменяется/удаляется экран, блок или кнопка — этот файл обновляется **в той же итерации**, а событие фиксируется в журнале изменений (внизу файла). Файл хранится рядом с планом: `/mnt/agents/output/Тили-тили_Карта_экранов.md`.
>
> Версия карты: **1.0** · обновлено 2026-09-01 · соответствует версии приложения `acbf0f8`.

---

> **Связанный документ:** `Тили-тили_Карта_кнопок.md` — детальная карта всех кнопок и обработчиков (правило **R-BTN**: любая новая/изменённая кнопка → обновить карту кнопок и журнал в ней в той же итерации).

## 0. Архитектура навигации

### 0.1. Каркас
- `App.tsx → Shell` — единый роутер. `app-shell` ограничивает ширину 430px (мобильный канвас).
- **TabBar** (плавающая стеклянная панель снизу) скрывается на: `/`, `/quiz`, `/invite`, `/auth`, `/dayx`, `/assistant`, чатах (`/us/chats/:id`), кабинете подрядчика (`/vendor-app*`).
- TabBar: `Главная /home` · `Поиск /search` · центральная 💍 `/wedding` · `Чаты /us/chats` · `Мы /us`.
- Guard: `/home` без онбординга → редирект на `/`. `*` → `/home` (если онбординг пройден) иначе `/`.

### 0.2. Store (`src/lib/store.tsx`) — состояние браузера (моки)
- Хук `usePersist(key, initial)` (`lib/usePersist.ts`) — state + localStorage. Используется: гости, чек-лист (задачи/галочки), чаты, рассадка, календарь подрядчика, лайки вдохновения.
- i18n: `lib/i18n.ts` — `t(s, lang)` / `useT()`, словарь EN ключевых строк (TabBar и др.).
- PWA: `public/sw.js` — app-shell кэш, офлайн-режим; регистрация в `main.tsx` (prod).
- Тесты: `vitest` — `src/lib/cities.test.ts` (7 тестов), `npm run test`.
| Поле/метод | Что делает |
|---|---|
| `onboarded` / `finishOnboarding(answers?)` | флаг прохождения квиза, persist `tt_onboarded`; с ответами — сохраняет их |
| `weddingDate` / `setWeddingDate()` | дата свадьбы `YYYY-MM-DD` или null, persist `tt_wedding_date`; от неё считаются подпись, «дней до» и обратный отсчёт |
| `quiz` | ответы квиза, persist `tt_quiz` |
| `slots` / `bookVendor(slotId, vendorName, price)` | слоты конструктора команды; бронирование подрядчика в слот |
| `cancelBooking(slotId)` | снимает бронь со слота (state→empty) — бюджет пересчитывается |
| `paySlot(slotId)` | статус слота «Оплачено полностью» (сделка → команда) |
| `favorites` / `toggleFav(id)` | избранные подрядчики, persist `tt_fav` |
| `lang` / `setLang(l)` | ru/en |
| `inviteTpl` / `setInviteTpl(t)` | выбранный сценарий приглашения (0–9), persist `tt_invite_tpl` |
| `inviteText` / `setInviteText(t)` | текст приглашения; редактор ↔ гостевая страница, persist `tt_invite_text` |
| `city` / `cityRegion` / `setCity(n, r)` | город свадьбы, persist `tt_city` / `tt_city_region` |

### 0.2.1. География (`src/lib/cities.ts`)
- Плоский список `City { n, r, d?, big? }`: n — название, r — субъект РФ, d — район, big — в «Популярных».
- Покрытие: крупные города РФ + **все райцентры Башкортостана** (Сибай, Баймак, Белорецк, Мелеуз, Туймазы, Давлеканово и др.) + соседние регионы (Челябинская, Оренбургская обл., Татарстан, Пермский край…).
- `searchCities(q, limit)` — поиск по подстроке (ё→е), префиксные совпадения первыми; ищет и по району.
- `POPULAR_CITIES` — стартовый экран пикера.
- **Компонент `CityPicker`** (`components/CityPicker.tsx`) — полноэкранный оверлей: живой автопоиск, группа «Башкортостан», популярные чипы, геолокация (navigator.geolocation → `nearestCity`, haversine по `CITY_COORDS`), пустое состояние. Используется в квизе и настройках.
- **Боевой план**: заменить/дополнить Яндекс Геокодер API (`geocode-maps.yandex.ru/1.x/?kind=locality&q=…`); контракт бэкенда: `GET /geo/cities?q=… → [{ id, name, region, district, lat, lon }]`.
