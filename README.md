# Тили-тили

Веб-приложение для подготовки и проведения свадьбы. Пара ведёт план, бюджет,
гостей и работу с подрядчиками. У гостей, подрядчиков и координатора свои
сценарии и права доступа.

## Общая проверка

Из корня проекта запустите `bash init.sh` с окружением из
[правил проекта](CLAUDE.md#4-команды). Версии Node и pnpm, команды и настройки
тестовых PostgreSQL и Redis заданы в [CI](.github/workflows/ci.yml).
