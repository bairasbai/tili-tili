## Окружение

- **Кластер один** — `postgresql-x64-16` на 5432 (ERR-0132); **база у тестов и dev-сервера общая** (R-177): полный прогон одной
  стороны за раз. Тестовые номера `+79RRRRRRNNN`: в базе их 82 000, случайный префикс может совпасть с прежним прогоном
  (ERR-0259) — `audit44` перебирает префикс до свободного, остальные файлы — при первом повторе тем же способом.
- **Хук `ruflo-core` 0.2.6 (плагин `claude-flow`) на каждой bash-команде** зовёт `npx --prefer-offline ruflo hooks post-command
  -c "<текст команды>"` через `cmd.exe` (`shell: true` для `.cmd`-шима): `cmd.exe` сам разбирает текст команды — `&&`, `||`, `|`,
  `>`, `<`, `2>` в нём исполняются ещё раз в cwd хука (`C:\Тили-тили`), одиночные кавычки не защищают (ERR-0252/0253, R-246/R-247).
  Отсюда файлы `100`, `250`, `1{exit}` в корне (`>`/`<` из awk/sed). Рабочий порядок этой сессии: чтение — Read/Grep; правки —
  Edit/Write и `.cjs` под `node <абс. путь>`; цепочки и прогоны — `bash <абс. путь .sh>` с замком `mkdir` (скрипты —
  `scratchpad/f015/`: `be-gate.sh`, `fe-gate.sh`, `be-check.sh`, `fe-check.sh`, `run-be.sh`, `fe-run.sh`, `gen.sh`, `maps.sh`).
  В тексте bash-команды — ни `&&`, ни `|`, ни `>`.
- Генераторы карт — `scratchpad/f015/maps.sh` (копии `inventory.cjs` + `mapgen.cjs` + `splice.cjs`; строки журнала —
  `journal-buttons-015.txt`, `journal-screens-015.txt`; шапка «2026-09-18 после ревью 015»; `VendorDetailView` — в «экранах
  без маршрута»).
- Забытый git-worktree `Тили-тили/app/.claude/worktrees/relaxed-roentgen-7581f1` (276 МБ, detached `2f00a07`) — по-прежнему
  вопрос владельцу (ERR-0255). `eslint .` из `app/` линтит и его, и вендорный `components/ui/` — гейт только по составу `init.sh`.
