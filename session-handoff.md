## Окружение

- **Кластер один** — `postgresql-x64-16` на 5432 (ERR-0132); роль `tili` без `CREATEDB` — репетиция миграций с нуля идёт в схеме
  `tili_fresh` той же базы (`npm run migrate:fresh`). **База у тестов и dev-сервера общая** (R-177): полный прогон одной стороны за раз.
- **Хук `claude-flow` повторяет каждую bash-команду ещё раз через `cmd.exe`, ПАРАЛЛЕЛЬНО** (ERR-0252/R-246, ERR-0253/R-247 — замки
  `mkdir` ДО старта, один на гейт; повторный вход ждёт `.done`) — главная опасность сессии: `;` там не разделитель, `-i`
  следующей утилиты становится флагом `sed`, `>`/`<` — перенаправлениями. Правила: читать файлы Read/Grep, писать Write; любые
  цепочки — файлом `.sh`/`.cjs` с абсолютными путями и флагами повторного входа; после команд с путями к документам — `git status
  --short`; документы коммитить сразу. Подмена файла для красного прогона — `scratchpad/f010/swapf.cjs head|back <путь>`
  (наборы — `scratchpad/f014/swap-all.cjs`, `swap-fe.cjs`). Прочие грабли: ERR-0240, ERR-0247, ERR-0248, ERR-0250, ERR-0251, ERR-0254
  (двоеточие в plain-скаляре YAML контракта — кавычки или `|`), ERR-0255.
- **Забытый git-worktree** `Тили-тили/app/.claude/worktrees/relaxed-roentgen-7581f1` (276 МБ, detached `2f00a07`, с 2026-09-04): `eslint .`

  владельца (ERR-0255).
- Генераторы карт — `scratchpad/f014/maps.sh` (inventory → mapgen → screens → splice под флагом; строки журнала —
  `journal-buttons-f014.txt`, `journal-screens-f014.txt`; шапка «после фич 011–014»).
