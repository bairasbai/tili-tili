# Передача сессии

Заполняется в конце работы — чтобы следующая сессия (или следующий агент) стартовала без археологии.
Перезаписывать целиком, история живёт в `JOURNAL.md`.

## Где остановились

**Фронтенд закрыт. Бэкенд: этапы 0–7 сделаны (у 7 три пункта ждут зависимостей), следующий — этап 8.**

`Тили-тили/backend/` — Fastify 5 на Node 22 с TypeScript. Сервер знает все 103 пути контракта: нереализованные отвечают `501`, несуществующие — `404`.

Работают: вход по коду из SMS, согласие на ПДн, профиль и настройки, сессии, экспорт данных, поиск городов, создание свадьбы с мозаикой и чек-листом, команда и роли, приглашения по ссылке, рефералы, каталог подрядчиков, анкета и календарь занятости, избранное, заявка консьержу, мозаика слотов, сделки, оплаты, бюджет, договоры, перенос и отмена свадьбы, гости и RSVP по токену, рассадка, чек-лист, тайминг, логистика, опрос меню, альбом, вишлист с резервами и складчиной, денежные фонды, «просим не дарить», чаты, уведомления, сдвиг тайминга и план Б. 115 из 131 операции контракта перестали быть заглушками.

**Матрица доступа включена и покрывает все пути со свадьбой в адресе** — в том числе те, обработчиков у которых ещё нет. Роль, которой путь не разрешён, получает 403 до заглушки 501.

**Матрица закрывает пути, но не поля.** Для роли, которой путь открыт на чтение, состав ответа проверяется отдельно: `budgetTotal` и коды приглашений вырезаются для всех, кроме `couple` (правило R-40). При добавлении путей на следующих этапах это надо повторять.

**Ссылку-приглашение выдаёт только пара** (решение владельца 2026-09-03). Список гостей ведёт вся команда, но выдача ссылки — это выдача удостоверения, по которому можно действовать от имени гостя.

**Гостевой токен — секрет, а стоит он в адресе.** Логгер маскирует второй сегмент у `/gifts`, `/rsvp`, `/join`, `/invite` и параметр `guestToken` (`src/redact.ts`, ERR-0050). **Добавляя гостевой путь, добавь его в этот список** — иначе токены снова поедут в лог хостера.

**Анонимность вишлиста держится на двух вещах сразу.** Резерв в ответе паре — это `exists(...)`: колонка `guest_token` не читается ни одним запросом пары. И перевыпуск ссылки-приглашения меняет токен гостя — иначе пара, которая ссылку выдаёт, обменяла бы её сама и увидела дарителя (ERR-0047). Резервы прежнего токена освобождает триггер. **Трогая гостевые токены на следующих этапах, это надо сохранить.**

**У этапа 7 три пункта не сделаны намеренно** — они упираются в зависимости, которые нельзя ставить без спроса: `@fastify/websocket` (доставка сообщения второму соединению), `bullmq` (расписание фоновых задач), `web-push` + ключи VAPID. Пока их нет: чат работает поллингом (§13.4 называет это штатным запасным путём), «печатает…» отвечает 501 `realtime_not_configured`, подписка на push — 501 `push_not_configured`, уведомления приходят в приложении. Вопрос вынесен в `tasks/todo.md`.

**Следующий шаг — этап 8** (кабинет подрядчика, отзывы, модерация; 9 дней). В BACKEND-PLAN.md он расписан; чекбоксы в `tasks/todo.md` предстоит разложить.

## Что нужно знать до первой команды

- Установка — **только pnpm**: `pnpm install --node-linker=hoisted`. `npm install` падает (`Exit handler never called!`, Node 25 + npm 11.12.1, ERR-0006).
- В `backend/` основной лок — `pnpm-lock.yaml`, в отличие от `app/`, где основной `package-lock.json`.
- Правка `openapi.yaml` обязана сопровождаться `node scripts/gen-contract.mjs` и `node scripts/gen-schemas.mjs` в той же итерации. Файлы `src/contract/*.generated.ts` коммитятся и руками не правятся; тесты сверки падают при расхождении.
- Базы и Redis локально нет — поднимаются `docker compose up -d db redis`. Без них сервер работает, `/health/ready` честно отвечает 503.
- Docker Desktop на этой машине сам не поднят — запускается командой `docker desktop start`.
- В образе лежит `.npmrc` с `minimum-release-age=0`: иначе сборка невозможна сутки после релиза любой зависимости. Локально защита сохраняется.
- Миграции: `DATABASE_URL=… node node_modules/node-pg-migrate/bin/node-pg-migrate.js -m migrations up`. Без них тесты этапа 1 упадут на отсутствующих таблицах.
- Код из SMS в разработке уходит в лог сервера — провайдера ещё нет.
- Ограничителей отправки кода три: на номер (5/час), на адрес (`OTP_MAX_PER_IP_HOUR`, 100/час) и общий потолок (`OTP_MAX_PER_HOUR_TOTAL`, 500/час). При долгой отладке они срабатывают на локальной базе — поднимать переменными, а не убирать из кода.
- `TRUST_PROXY` — число прокси впереди. Пусто = не доверять `X-Forwarded-For`. За балансировщиком Timeweb ставится 1, иначе ограничитель по адресу не различает клиентов.
