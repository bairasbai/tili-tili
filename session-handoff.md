## Окружение

- **Кластер один** — системная служба `postgresql-x64-16` на порту 5432, стартует сама.
  Второй поднимать нельзя: два кластера на один порт — вопрос лишь того, кто стартовал
  первым, и после перезапуска машины база «исчезает» вместе с данными проверок (ERR-0132).
- **Бэкенд стартует `npm run dev`** — переменные берутся из `backend/.env` (в репозиторий
  не попадает, шаблон `.env.example`). Пустое значение переменной — это «не задано», а не
  ноль: `envNumber` / `envText` в `src/config.ts` (ERR-0133).
- **Осиротевший кластер** `AppData/Local/tili-pg` остановлен и оставлен на диске как есть.
  Сейчас он не может порождать процессы (`0xC0000142`, лечится перезагрузкой). Если данные
  прошлых прогонов когда-нибудь понадобятся — поднимать только на порту 5433.
- Код подтверждения при пустом `SMS_PROVIDER` уходит в лог процесса — оттуда его и берут
  при проверке в браузере. Фронт — порт 3000, `/api` проксируется на `127.0.0.1:3001`.
- **Смена секретов гасит все выданные токены**: после перезапуска с новыми секретами в
  браузере нужно войти заново.
