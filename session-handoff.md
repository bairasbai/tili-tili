## Окружение

- **Кластер один** — `postgresql-x64-16` на 5432, второй не поднимать (ERR-0132). Роль `tili` без `CREATEDB` —
  миграции на пустой базе здесь не прогнать (`RELEASE-BLOCKERS.md` №22); `down`/`up` на живой — можно.
- **База у тестов и dev-сервера общая** (R-177): полный прогон одной стороны за раз; агенты — только свои файлы по одному.
- **Миграции с заполнением данных** — сначала замер по операторам в транзакции с `ROLLBACK` (`scratchpad/f005/mig1-timing.cjs`),
  set-based, под `timeout` (ERR-0246). `NOT VALID` — для проверок, которые старые тестовые строки нарушают.
- **Грабли инструментов** — ERR-0240 (`String.replace` с `$`), ERR-0247 (`>` под хуком → пустой файл; мусор в корне),
  ERR-0248 (бэктики в `node -e` выполняются bash — тексты только файлом-скриптом или Write). PostToolUse-хук `claude-flow`
  повторяет команды — скрипты идемпотентны. `SendMessage` в этой сессии недоступен — агентов после обрыва перезапускать
  новым `Agent` с `RESUME.md` (они дочитывают свой отчёт и `git diff`).
- Генераторы карт (`inventory.cjs`, `mapgen.cjs`, `splice.cjs` в записях сессии): `node inventory.cjs app/src > inventory.tsv;
  node mapgen.cjs app/src backend inventory.tsv > map.md; node mapgen.cjs … screens > screens.md; node splice.cjs
  Тили-тили map.md screens.md <строка-кнопок> <строка-экранов>` — `mapgen` теперь видит запрос за функцией, переданной
  аргументом (`openChat(…, dayChatRoute)`).
- Лимит API сессии срабатывает (429) — агенты гибнут; отчёт «по ходу» + перезапуск через `RESUME.md` восстанавливает
  работу без потерь (четыре агента фичи 005 пережили это один раз).
