## 23 ноября 2026 · T025, частичная автоматическая рассадка

После последовательной записи нескольких гостей отказ одного PATCH оставлял возможность использовать устаревший список мест при повторе. Подготовлена правка на основе PR #349: после любого сбоя автоматической рассадки выполняется повторное чтение, а после частичного сохранения выводится явное RU/EN сообщение. При прерывании по offline generation показывается предупреждение; кнопку блокирует загрузка/обновление. Добавлен RU/EN регрессионный сценарий с успешным первым PATCH и последующим HTTP 409.

Код опубликован в продолжении ветки `codex/continue-wedding-20261123`. Проверки фронтенда/браузера и физического диктора должны быть подтверждены по фактическому CI на новом SHA; не переносить результаты `23fea400` на обновлённую версию.
