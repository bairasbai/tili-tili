## Живая проверка: как войти

Код входа лежит хешем в `otp_codes`; готовый скрипт — `backend/scripts/dev-token.sh +7…` (нужны локальная база и
`JWT_REFRESH_SECRET` из `.env`); в записях сессии — `audit-scripts/audit-login.mjs <телефон>` (скопировать в
`backend/`, запустить при поднятом dev-сервере, убрать). Refresh-токены ротируются: после 401 входить заново. Токены в
браузер кладутся в `localStorage.tt_auth` как `{accessToken, refreshToken}`.

## Окружение

- **Кластер один** — служба `postgresql-x64-16` на 5432. Второй не поднимать (ERR-0132). Роль `tili` без
  `CREATEDB`, пароля `postgres` нет — миграции на пустой базе прогнать здесь нельзя (`RELEASE-BLOCKERS.md` №22).
- **Бэкенд** — `npm run dev` (127.0.0.1:3001), переменные из `backend/.env`; dev-сервер подхватывает правки сам.
  Фронт — 3000, `/api` в прокси. Панель предпросмотра: оба сервера в `C:\Тили-тили\.claude\launch.json` (`tili-app`,
  `tili-backend`); вкладка приложения в этой сессии — `tab-1`, бэкенда — `seed`.
- **База у тестов и dev-сервера общая** (R-177): сначала прогон, потом живая проверка. Шесть параллельных агентов дают
  54–90 % CPU — фронтовые прогоны в это время красные на таймаутах; гонять полные наборы, когда агенты закончили.
- **Грабли инструментов** — ERR-0186 (NUL), ERR-0194/0214/0215 (общая база), ERR-0240 (`String.replace` с `$` в тексте —
  только `slice` или функция-замена); `awk 'NR>=N'` и `sed -n` в агентах создают файлы-мусор в корне — переносить в
  записи сессии; heredoc с кириллицей ломается — тексты через инструмент записи и `git commit -F файл`; `grep -P` в
  этой оболочке не работает (локаль) — NUL/CRLF сканировать `node` (`scratchpad/nulscan.cjs`).
- Генераторы карт (`inventory.cjs`, `mapgen.cjs`, `splice.cjs`) живут в записях сессии: `node inventory.cjs app/src >
  inventory.tsv; node mapgen.cjs app/src backend inventory.tsv > map.md; … screens > screens.md; node splice.cjs
  Тили-тили map.md screens.md <строка-журнала-кнопок> <строка-журнала-экранов>`. Подписи кнопок главной генератор не
  вытаскивает (`(без текста)`) — журнальная строка называет их словами.
- Лимит API сессии за ночь срабатывал трижды (429) — агенты погибают без отчёта; в задании фиксерам стоит «пиши отчёт по
  ходу», а при перезапуске — `RESUME.md` (продолжить от `git diff` своих файлов).
