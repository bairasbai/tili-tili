## Что нужно знать до первой команды

- Установка — **только pnpm**: `pnpm install --node-linker=hoisted`. `npm install` падает (`Exit handler never called!`, Node 25 + npm 11.12.1, ERR-0006).
- В `backend/` основной лок — `pnpm-lock.yaml`, в отличие от `app/`, где основной `package-lock.json`.
- Правка `openapi.yaml` обязана сопровождаться `node scripts/gen-contract.mjs` и `node scripts/gen-schemas.mjs` в той же итерации. Файлы `src/contract/*.generated.ts` коммитятся и руками не правятся; тесты сверки падают при расхождении.
- Базы и Redis локально нет — поднимаются `docker compose up -d db redis`. Без них сервер работает, `/health/ready` честно отвечает 503.
