# План FR-016

1. Сверить расчёт бюджета, существующие настройки лимитов и резерва, видимость по ролям и сценарии неизвестных сумм.
2. Добавить отдельную таблицу вклада семьи и закрытый API бюджета. Хранить суммы обещания и получения в копейках, проверять версию при записи и оставлять изменения в истории. Уведомления Тиля и общая проекция расходов сохраняют собственные данные.
3. Показать вклад и неопределённые суммы в бюджете. Сохранить существующий расчёт расходов и исключить повторный учёт одного вклада.
4. Проверить сохранение прежних данных при миграции PostgreSQL, конкурирующие изменения, отказ посторонним и Chrome. Опубликовать проверенный блок.
