# План FR-014

1. Расширить существующую составляющую предложения опциональной формулой с единицей, количеством и ставкой. Сохранить прежние снимки без формулы.
2. Считать произведение в целых минорных единицах с точной десятичной арифметикой. Для положительных сумм использовать округление до ближайшей копейки с округлением половины вверх, как в существующем денежном вводе. Отдельно проверить предел точного целого.
3. Показать редактор формулы исполнителю и все исходные поля паре в существующем сравнении. Значения не должны заменяться догадкой, если одно из условий отсутствует.
4. Проверить старые предложения, ввод, округление, неизвестные значения и снимок принятой версии. Изменение параметров сравнения и согласование новой сметы относятся к FR-015.
