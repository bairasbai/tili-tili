# WP12 / FR-014 · расчётные доплаты

Для отдельной доплаты исполнитель указывает фиксированную сумму или расчёт по единице. Расчёт показывает единицу, количество и ставку. Пара видит эти поля рядом с суммой в предложении и в сравнении.

Если количество или ставка ещё неизвестны, строка явно остаётся неуточнённой и исключается из известной оценки. При отправке версии сервер пересчитывает известную сумму из ставки и количества. Принятая версия сохраняет свою формулу. Сам расчёт не меняет сумму брони.
