# Спека: Заполненность анкет на дашборде

**Папка:** tasks/фичи/012-заполненность-анкет · **Заведена:** 2026-09-13 · **Статус:** в работе (малая фича — одна карточка панели, без
цикла вопросов; определение метрики записано ниже). Закрывает остаток `RELEASE-BLOCKERS.md` №23 (План §19.10 п. 4 «дашборд:
заполненность анкет»).

## Зачем

Панель сотрудника показывает число опубликованных анкет, но не говорит, какие они: анкета из одного названия и анкета с описанием,
ценой, телефоном и пакетами считаются одинаково. Владельцу нужно видеть, насколько каталог «живой», а не только большой — иначе
«готов к запуску: 50 анкет» может означать пятьдесят пустых карточек.

## Определение (Р1)

Заполненность анкеты — доля заполненных из четырёх необязательных полей, которые подрядчик может заполнить сам сегодня: **описание**
(`about`), **рабочий телефон** (`phone`), **цена «от»** (`price_from`), **хотя бы один пакет** (`vendor_packages`). Фото и видео не
считаются: загрузки файлов нет ни у кого до хранилища (блокер №3) — метрика штрафовала бы всех за инфраструктуру. Считается по
живым опубликованным анкетам (тот же набор, что `vendorsPublished`). «Полная» — 4 из 4.

## Требования

- **FR-001** Контракт v0.35.0: `AdminMetrics.profiles { published, complete, averagePercent }` — все три integer; `averagePercent`
  0…100, округлённый; при `published = 0` — `averagePercent = 0` и `complete = 0` (пустой каталог — ноль по факту, не «неизвестно»:
  ответ сервера есть).
- **FR-002** Бэкенд `GET /admin/metrics`: один запрос по опубликованным живым анкетам (`VENDOR_LIVE_JOIN`, `published_at`), поля по
  определению Р1.
- **FR-003** Фронт `/admin`: карточка «Заполненность анкет» — «средняя N%» · «полных M из K»; до ответа — прочерки без цифр.
- **FR-004** Тесты красные без фикса: бэкенд — три анкеты (пустая, 2 из 4, полная) → `averagePercent` и `complete` по определению,
  неопубликованная не считается; фронт — карточка из ответа, прочерки до ответа.

## Не входит

Заполненность по категориям и городам; напоминания подрядчикам о пустых полях (отдельная фича — уведомления кабинету); фото/видео
в метрике (после хранилища — пересмотреть определение).
