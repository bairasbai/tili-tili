## Фазы

### Фаза 1 — миграции и контракт (В1–В3) · ~1 час
1. `timeline_events.for_guests boolean not null default true`.
2. `messages.guest_id` + CHECK `num_nonnulls(sender_id, guest_id) <= 1`, индекс `(chat_id) where guest_id is not null` не нужен.
3. Контракт v0.32.0: `TimelineEvent.forGuests`, `Message.guestName`, `GET /join/{guestToken}/day`, `GET/POST
   /join/{guestToken}/day-chat/messages` (423 `chat_closed_for_guests`), описания.

### Фаза 2 — бэкенд · ~3 часа
`day.ts`: `PUT …/timeline` принимает `forGuests`; `GET /join/{t}/day` собирает всё одним обработчиком (тайминг `where
for_guests`, стол через `guests.table_id → tables.name`, автобус через `bus_bookings` + `BUS_SELECT` с `carrier`, координатор —
`wedding_members role='coordinator' join users` (имя, телефон), окно чата по `chats.opens_at` дня X); чат гостя — лента по
курсору из чата `kind='day'` и запись с `guest_id`; `chats.ts` — `guestName` (`left join guests`) и `system` только при пустых
обоих. Тесты `audit38`: гость видит только гостевые блоки; стол/автобус свои; координатор с телефоном; вне окна 423 с
`opensAt`; реплика гостя у пары с именем; CHECK прямым SQL → 23514.

### Фаза 3 — фронт · ~3 часа

## Открытые технические вопросы

- Уведомление команде о реплике гостя — тем же `notifyOthers`, что у участника; частота — не чаще, чем у людей (антиспам не нужен: гостей ограничивает список).
- «Построить маршрут» — ссылка `https://yandex.ru/maps/?text=<адрес>` без гео; заглушек не ставим.
