# Этап 017-A — задачи: отчёт проверки

Дата: 2026-09-26. Ветка `feature/product-improvements-stage1-tasks`; слияние в main не разрешено и не выполнялось.

## Реализовано

- Ответственный из живых участников своей свадьбы, фильтры «Мои задачи» / «Без ответственного» / «Все задачи».
- Точная дата, fixed/relative и явное снятие срока; редактирование с подтверждением, а не запросом на каждый ввод.
- Транзакционная проверка назначения; удаление участника/аккаунта и смена недопустимой роли снимают назначение.
- Сохранены прежние title/done/period, права доступа и ограничения системных/planb-задач.
- Исправлены чужие поля в форме бюджета, отсутствующий импорт профиля и неверное размещение параметра mine в контракте.
- OpenAPI 0.42.0 и все generated-файлы пересобраны штатными генераторами.

Финальный прогон — БД с C.UTF-8: первый тестовый кластер с C локалью неверно обрабатывал регистр кириллицы, это отдельно устранено настройкой нового тестового кластера, а не ослаблением тестов.

## Браузер и удалённые проверки

Подготовлен отдельный workflow `Task planning browser E2E`: реальный HTTP API, две независимые Chromium-сессии, PostgreSQL в GitHub Actions, проверка сохранения/перезагрузки/выполнения вторым пользователем/переноса свадьбы/снятия назначения. В artifacts допускаются только скриншот и итог, без fixture-токенов.

Локальный Chromium не разрешает localhost по управляемой политике окружения. Политика не отключалась. До появления успешного результата этого workflow браузерная проверка не считается выполненной. Результат GitHub CI и браузера фиксируется отдельно после публикации кода.

## Незакрыто

- 017-B: индивидуальные настраиваемые напоминания и уведомления назначения ещё не реализованы.
- В первом полном прогоне один раз воспроизведена взаимоблокировка существующей операции бронирования слота (audit4: 200/500 вместо 200/409). Она подтверждена журналом PostgreSQL; отдельный повтор и финальный полный прогон прошли. Код бронирования этим коммитом не изменён, риск нельзя считать закрытым лишь по одному зелёному повтору.
- Платежи, сравнение пакетов, семейные приглашения и остальные этапы roadmap не реализованы этим этапом.
- Настройка боевых SMS/S3/push, юридические документы и эксплуатационная репетиция восстановления production не выполнялись.

Проверенные задачи и перечисленные следующие работы — разные статусы. Этот отчёт не означает завершение всего roadmap или готовность production.
