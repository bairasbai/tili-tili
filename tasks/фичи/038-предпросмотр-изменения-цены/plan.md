# План FR-015 · предпросмотр

1. Использовать финансовую проверку доступа к заказу и сохранённую разбивку принятого предложения. Для старых и внешних броней без формул показать, почему оценка недоступна.
2. Переиспользовать расчёт доплаты из FR-014 и сравнить суммы по исходным и новым количествам. Проверить уменьшение, точный ноль, неполные данные и допустимый диапазон.
3. Показать предпросмотр в заказах пары и исполнителя. Проверить доступ сторон, срок действия данных, отсутствие изменений в цене, платежах и истории, сценарий в Chrome.
4. Опубликовать предпросмотр отдельно. Продолжить с согласованием финансовой поправки.
