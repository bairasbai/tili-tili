Эти числа получены как 94+1+1 и 124+1+1; существующие таблицы не удаляются и не исключаются из наблюдения. Это не production-блокировка: часть HTTP500 в полном прогоне возникает в тестовых наблюдателях, которые утверждают ровно124 и откатывают транзакцию.

У96 — immutable action ledger с составными FK message→chat→wedding и question→original sender, строгими kind/payload/state/result, 24часа только для pending; task.revision увеличивает DB-триггер при каждом UPDATE и не принимает клиентское назначение. Down с непустым ledger отказывает. Изменение живой prod-базы этим планом не разрешено.

Состав source witness расширить новыми манифестами, DDL, featuretests и drill; условия94 для вложенных доказательств сохраняются для всех >=94.
