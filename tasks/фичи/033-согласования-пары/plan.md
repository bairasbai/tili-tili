# FR-007 · план реализации

Раздел «Согласования» в плане свадьбы работает с отдельным списком добровольных согласований. Партнёра выбирают среди действующих участников пары. При создании запроса никто ещё не ответил.

Хранить решение и его редакции в PostgreSQL. В каждой редакции два отдельных ответа. Принятая редакция сохраняется при последующих предложениях. API сверяет ожидаемый номер редакции и текущие права под блокировкой свадьбы, которую используют изменения состава команды.

Проверить существующими средствами проекта типы, контракт, изоляцию ролей, две одновременные операции и сохраняющую миграцию. Интерфейс проверить с двумя синтетическими учётными записями. Правила проекта и существующие действия сохраняются.
