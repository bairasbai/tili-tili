# Отдельная позиция мероприятия · 16 октября 2026

Основание: следующий публичный шаг WP04/A03 после PR67 (main d98b30b). Это одна ограниченная поставка; полный A03, SC004 и WholeWP0/17 остаются открыты.

1. Добавить явный POST /weddings/{weddingId}/slots/additional с categoryId, programEventId, label и обязательным Idempotency-Key. Только текущая пара, активная свадьба и её мероприятие; максимум100 позиций. Повтор ключа с иным телом/путём — конфликт. После ожидания повторно проверить членство, сессию, согласие и JWT. Повтор не создаёт вторую позицию/аудит. Старый POST /slots с categoryId сохраняет slot_exists. Создание позиции не создаёт заказ, бронь или финансовую запись.
2. Форма на экране команды: актуальные категории/мероприятия/роль, явные выборы и название, loading/error, безопасный ручной повтор того же запроса при неизвестном результате. Создание подтверждается сервером. Переход в конкретный slot; каталог и анкета сохраняют slotId, недействительный explicit slot не заменяется первой позицией категории.
3. Контракт → штатная генерация. Целевые HTTP/native регрессии, UI проверки, независимое актуальное ревью, полный gate и compiled browser на своём локальном стенде. PG/Redis/browser/GitHub только Root, последовательно. Старые FAILED и чужие рабочие копии сохраняются, production запрещён.
4. Обновить карты экранов/кнопок, журнал, todo/handoff, зафиксировать фактические проверки и уборку. Публикация только после обязательных проверок в пределах действующего разрешения; состояние CI/merge подтверждать отдельно.

Уточнение после проверки интеграции: существующий PUT кандидата получает необязательный slotId. Явный контекст проверяет конкретную позицию/категорию и текущие права после ожидания, без fallback. Это сохраняет работу списка кандидатов при переходе из обычных карточек и позволяет несколько позиций одной категории. Без slotId прежний выбор категории сохранён. Общий предел100 проверяется также перед созданием новой категории в legacy POST и shortlist PUT; использование существующей позиции при пределе остаётся доступным.
