# Ревью 018-A и 018-B — находки, вердикты, решения

**Ветка:** `claude/review-018a-018b-roadmap-kqhovt` (черновой PR №3 в `feature/product-improvements-stage1-tasks`).
**Дата:** 2026-09-26. Код 018-A/018-B пришёл transfer-архивами владельца и лёг двумя коммитами «как поставлен»:
`e7a27e4` (018-A) и `08d7953` (018-B). Целостность архивов проверена по манифестам и хешам blob до наложения.

## Как проверяли

| Направление | Кто | Метод |
|---|---|---|
| 018-A: права и приватность (P), контракт и тесты (C), деньги и модель (M), экран (F) | четыре независимых ревьюера | чтение диффа `e7a27e4` построчно против CLAUDE.md §5 и правил ERRORS.md |
| 018-B: сервер (BB), экран, контракт и тесты (BF) | два независимых ревьюера | то же для `08d7953` |
| 018-A: регрессионные тесты | исполнитель тестов | каждый тест красный на `7ef72a5` (до ревью), где дефект был; где поведение уже было верным — мутация кода |
| 018-B: регрессионные тесты | основной поток | мутации сервера (11) и фронта (9): каждое исправление откатывалось по одному, тест обязан покраснеть |

## Остаётся — не закрыто в этой ветке

1. **Пределы «5 файлов на оплату», квота свадьбы, 500 этапов на сделку** держит код под замком (BB-11) — это защитные
   пределы, а не доменные инварианты; гонку за последнее место проверяет тест BB-09.
2. **Формула обязательств в `fairPrice` для гостей** (M-07) — отдельным текстом; совпадает с бюджетом, пока обе стороны
   зовут `expireHolds`.
3. **Браузерный E2E на GitHub (C-14)** срабатывает только на ветке PR №1: на PR №3 его прогон — локальный
   (2026-09-26, Chromium 141, 14/14), удалённого запуска этой версии нет.
4. **Дневная квота загрузок на человека (BB-01)** не сделана: без индекса по `audit_log.actor_id` счёт — полный проход
   журнала. Рост ограничен квотой свадьбы и выключенной по умолчанию загрузкой; частота — ограничителем запросов.
5. **Число оплат на сделку** не ограничено (BB-01, отметка в 1 копейку) — вне 018, поведение до 018 то же.
6. **17 тегов контракта не объявлены в корневом `tags`**, в том числе `payments` (BF-15) — так с давних пор, не дефект 018.

## Решения владельца

`questions.md` — пять вопросов с вариантами по умолчанию. До ответа действуют умолчания: загрузка чеков выключена (1Б),
копейки в формах платежей остаются (2А), история отменённой свадьбы — как сейчас, 404 (3А), правил на размер лимитов нет
(4А), удалять чек может любой из пары, журнал без имени файла (5А).
