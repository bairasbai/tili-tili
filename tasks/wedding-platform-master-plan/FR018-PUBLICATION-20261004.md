# FR018: сравнение условий предложения

Сохранено проверенное состояние draft, браузерная приёмка открыта 2026-10-04T09:51:10.675Z.

Пара видит рядом условия предложений подрядчиков: часы, команду, результат, срок сдачи, дополнительные расходы, отмену и перенос. Условия сохраняются буквальным текстом; отсутствующее поле остаётся NULL. После принятия в сделке хранится неизменяемый снимок выбранного предложения. Изменения каталога подрядчика его не заменяют. При принятии старой версии API возвращает 409, интерфейс предлагает обновить предложения.

Календарь показывает наблюдавшуюся занятость дня и время наблюдения. Помощник не получает приватные условия; чужая свадьба недоступна.

Миграция 1763825000000 добавляет comparison_terms к offers и offer_comparison_terms_snapshot к deals. Старые записи остаются NULL. Откат отказывается удалять заполненные условия. Сохранение старых строк, ограничений и связей проверено на реальном PostgreSQL при 82→83 и повторном up.
