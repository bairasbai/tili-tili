# Правила агентов Тили-тили

- Перед работой прочитай [CLAUDE.md](CLAUDE.md) в этом рабочем дереве. Там проектные ограничения, источники правды и обязательные проверки для Codex и Claude.
- Проверь выбранное дерево, ветку, локальный статус и [текущую передачу](session-handoff.md). Используй своё подходящее дерево. Новую копию создавай для нужной изоляции и убирай по общим правилам после сохранения результата.
- По [общим правилам безопасной работы с GitHub](docs/agent-rules/github-api-guard.md) начни с локальной сверки, соблюдай бюджет и паузы; если страж установлен в окружении — проверь его статус. Документ не выдаёт агенту доступ к аккаунту. Слияние, публикация и тестирование на рабочей инфраструктуре подчиняются разрешениям проекта.

## Общие правила работы агентов

- Любой ИИ-агент (Codex, Claude, Gemini, Copilot и другие) с доступом к репозиторию обязан соблюдать [правила GitHub, авторизации и лимитов](docs/agent-rules/github-api-guard.md).

- При проверке изменений поведения, изменении условий приёмки или ревью существенной спецификации открой [правила проверки и независимого ревью](docs/agent-rules/verification-and-review.md).
- При ускорении приложения или изменении интеграции с OpenAI API открой [правила производительности и OpenAI API](docs/agent-rules/performance-and-openai.md).
- При разрешённом делегировании используй [правила оркестрации](.agents/skills/tili-orchestrate/SKILL.md).
