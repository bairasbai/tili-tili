# Инструкции Gemini для Тили-тили

Основные правила всех агентов: [AGENTS.md](AGENTS.md); полный проектный контракт: [CLAUDE.md](CLAUDE.md); условия доступа и безопасного использования GitHub: [docs/agent-rules/github-api-guard.md](docs/agent-rules/github-api-guard.md).

Сначала сверяй локальную ветку, `session-handoff.md`, `tasks/todo.md` и реестр приёмки. Работай в своей отдельной ветке; не удаляй чужие правки и не сливай в `main` без отдельного разрешения. Прерывай GitHub-обращения при лимитах, не запускай циклический опрос и не используй чужие секреты. Доступ к GitHub настраивает владелец во внешней среде, этот файл его не предоставляет.
